## O que poderia ter sido diferente

### 1. Pre-flight check de plugins externos (lesson dedicada)

Adicionar ao orchestrator pré-flight: validar que TODO plugin `origin: "global"` em `/root/.openclaw/extensions/` e `/root/.openclaw/npm/node_modules/@openclaw/` tem `dist/index.{js,mjs,cjs}` ou `index.{js,mjs,cjs}` adjacente. Detalhes em `2026-05-05-openclaw-v5.4-graph-memory-build-required.md`.

### 2. Sessions cleanup periódico

17 stuck sessions é debt acumulado. CLAUDE.md regra #5 cobre, mas não tem cron rodando o cleanup. Adicionar:
```bash
# /root/.openclaw/scripts/sessions-cleanup-stuck.sh (cron diário 04:00 BRT?)
for a in nox atlas boris cipher forge lex main; do
  f=/root/.openclaw/agents/$a/sessions/sessions.json
  [ -f "$f" ] || continue
  STUCK_BEFORE=$(jq '[to_entries[] | select(.value.model | tostring | test("^(gemini|openai|gpt-)"))] | length' "$f")
  if [ "$STUCK_BEFORE" -gt 0 ]; then
    cp "$f" "$f.bak-$(date +%Y%m%d-%H%M)"
    jq 'with_entries(select(.value.model | tostring | startswith("claude-") or startswith("anthropic-") or startswith("anthropic/")))' \
      "$f" > /tmp/clean && mv /tmp/clean "$f"
    logger -t sessions-cleanup "$a: cleaned $STUCK_BEFORE stuck sessions"
  fi
done
```
Decisão pendente: rodar diário ou semanal? Crons são DESIGN em haiku-4-5/gemini-flash-lite (regra #1) — não confundir com fallback grudado.

### 3. Tailscale config drift há tempo

`gateway.tailscale.mode = "serve"` provavelmente foi setado em algum upgrade antigo e nunca foi questionado. Falhava a cada ~15min nos logs há semanas/meses sem ninguém perceber (silenciado entre outros logs). Auditoria periódica de config drift seria útil — `openclaw config get` walk para identificar settings nunca confirmados.

### 4. Registry refresh post-upgrade

`openclaw plugins registry --refresh` deveria ser parte do orchestrator Phase 5 (após qualquer mexida em plugin manifest). Não é hoje.

### 5. graph-memory build hygiene

Plugin foi instalado em 2026-04-19 e nunca compilado. Confiar em jiti fallback é frágil. Estabelecer norma: todo plugin TypeScript precisa de `npm run build` documentado + `dist/` checked in (ou rebuild em deploy). Para plugins pesados como graph-memory (96KB bundled, 4 tools, vector search), ter compile gate é importante.
